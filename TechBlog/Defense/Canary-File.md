# Canary File — 침입 탐지용 미끼 파일

## 정의

시스템 보안, 침입 감지 또는 문제 해결을 위해 사용되는 파일로서, **무단 접근, 변조, 또는 장애를 탐지**하기 위해 중요한 디렉터리에 배치되며, 해당 파일에 대한 접근, 수정, 삭제를 지속적으로 모니터링하는 파일입니다.

---

## 주요 사용 용도

### 침입 감지
- **목적:** 민감한 위치에 유인 파일로 배치하여 공격자가 파일에 접근하거나 수정했을 때 이를 감지
- **작동 방식:**
  - 중요한 디렉터리에 파일을 배치
  - 파일에 대한 접근, 수정, 삭제를 지속적으로 모니터링
  - 파일에 변화가 발생하면 관리자에게 알림
- **사용 예시:**
  - 웹 서버의 루트 디렉터리에 카나리아 파일을 배치하고, 공격자가 파일에 접근하면 침입 신호로 간주

### 시스템 모니터링 및 문제 해결
- **목적:** 시스템 가용성 또는 성능을 테스트하고 모니터링
- **작동 방식:**
  - 카나리아 파일의 존재 여부 또는 무결성을 주기적으로 확인
  - 파일이 손상되거나 없어지면 시스템에 문제가 있음을 알림

### 이메일 스팸 필터링 (카나리아 토큰)
- **목적:** 이메일 주소가 무단으로 사용되는지를 추적
- **작동 방식:**
  - 파일에 고유한 이메일 주소(카나리아 토큰)를 삽입
  - 해당 이메일 주소로 이메일이 수신되면 파일이 접근당했음을 확인

### 랜섬웨어 방지
- **목적:** 랜섬웨어 활동을 탐지
- **작동 방식:**
  - 랜섬웨어가 공격할 가능성이 높은 디렉터리에 카나리아 파일을 배치
  - 파일이 암호화되거나 삭제되면 랜섬웨어 활동을 알리는 신호로 작동
