# T1560.001 — Archive Collected Data: Archive via Utility

## 개요

**TA0009 / T1560.001**  
수집된 데이터를 7zip, WinRAR, zip 등의 아카이브 유틸리티로 압축하는 기법입니다. 데이터 유출 전에 파일을 압축하여 전송 크기를 줄이고, 패스워드 암호화를 통해 DLP 솔루션의 내용 검사를 우회합니다.

---

## 동작 방식

1. T1005 등으로 수집된 파일을 임시 디렉토리에 통합
2. 아카이브 유틸리티로 압축 (패스워드 암호화 적용)
3. 압축 파일을 C2 채널 또는 클라우드 스토리지로 유출 (T1041, T1567)
4. 증거 인멸을 위해 원본 파일 및 임시 파일 삭제

**암호화 아카이브 사용 이유:**
- 전송 크기 최소화
- DLP 내용 검사 우회 (암호화된 컨텐츠 분석 불가)
- 탐지 회피

## 주요 커맨드 / 실습

### 7-Zip
```cmd
# 패스워드 암호화 압축 (AES-256)
7z a -p"S3cr3tP@ss!" -mhe=on C:\temp\exfil.7z C:\temp\collected\

# 분할 압축 (대용량 파일 분할 전송)
7z a -p"S3cr3tP@ss!" -v100m C:\temp\exfil.7z C:\temp\collected\

# 재귀 압축
7z a -r -p"S3cr3tP@ss!" archive.7z C:\Users\target\Documents\
```

### WinRAR
```cmd
# 패스워드 암호화 RAR 아카이브
rar a -hp"S3cr3tP@ss!" C:\temp\exfil.rar C:\temp\collected\

# 파일 헤더도 암호화 (-hp 옵션)
winrar a -hp"S3cr3tP@ss!" exfil.rar *.docx *.xlsx *.pdf

# 분할 압축
rar a -hp"pass" -v50m exfil.rar C:\temp\collected\
```

### PowerShell Compress-Archive
```powershell
# 기본 ZIP 압축 (패스워드 미지원 - 탐지 용이)
Compress-Archive -Path C:\temp\collected\* -DestinationPath C:\temp\exfil.zip -Force

# 특정 파일 유형만 압축
Get-ChildItem -Path C:\Users -Recurse -Include "*.docx","*.xlsx","*.pdf" |
    Compress-Archive -DestinationPath C:\temp\docs.zip

# 기존 아카이브에 추가
Compress-Archive -Path C:\temp\newfile.txt -DestinationPath C:\temp\exfil.zip -Update
```

### Linux tar / zip
```bash
# tar로 압축 (gzip)
tar czf /tmp/exfil.tar.gz /home/user/Documents/

# zip 패스워드 암호화
zip -r -P "S3cr3tP@ss!" /tmp/exfil.zip /home/user/Documents/

# 특정 파일 유형만 압축
find /home -name "*.pdf" -o -name "*.docx" | tar czf /tmp/docs.tar.gz -T -

# openssl로 암호화 후 압축
tar czf - /home/user/Documents/ | openssl enc -aes-256-cbc -pass pass:S3cr3tP@ss! -out /tmp/exfil.enc
```

## 탐지 방법

### Sigma Rule
```yaml
title: Suspicious Archive Creation in Temp/Public Directories
id: b7e4a1c3-9f5d-4e8b-a2c6-3d1f7e5b9a4c
status: stable
description: Detects archive utility execution in suspicious directories indicating data staging
logsource:
    product: windows
    category: process_creation
detection:
    selection_tools:
        Image|endswith:
            - '\7z.exe'
            - '\7za.exe'
            - '\rar.exe'
            - '\winrar.exe'
    selection_paths:
        CommandLine|contains:
            - '\Temp\'
            - '\Users\Public\'
            - '\Windows\Temp\'
    condition: selection_tools and selection_paths
falsepositives:
    - Legitimate software installations
    - IT backup scripts
level: medium
tags:
    - attack.collection
    - attack.t1560.001
```

## 대응 방안

1. 임시 디렉토리(`%TEMP%`, `C:\Windows\Temp`)에서의 아카이브 생성 모니터링
2. DLP 솔루션으로 암호화 아카이브 파일 전송 탐지
3. 프로세스 실행 감사 로그로 7z/rar 실행 탐지
4. 네트워크 트래픽 용량 이상 탐지 (대용량 전송)
5. 아카이브 도구 실행 허가 목록(Allowlist) 관리
