# T1087.002 — Domain Account Discovery

## 개요

**TA0007 / T1087.002**  
도메인 내의 사용자 계정, 그룹, 권한 정보를 열거하는 기법입니다. 공격자는 도메인 관리자, 서비스 계정, 특권 그룹 멤버십을 파악하여 고가치 대상을 식별하고 공격 경로를 계획합니다.

---

## 동작 방식

1. 도메인 사용자 계정 전체 목록 열거
2. 특권 그룹(Domain Admins, Enterprise Admins 등) 멤버십 확인
3. 서비스 계정, Kerberoastable 계정 식별
4. BloodHound 등으로 공격 경로(Attack Path) 시각화
5. 고가치 대상 계정 선정 후 집중 공격

---

## 주요 커맨드 / 실습

### 기본 net 명령어
```cmd
# 도메인 사용자 열거
net user /domain

# 도메인 그룹 열거
net group /domain

# 특정 그룹 멤버 확인
net group "Domain Admins" /domain
net group "Enterprise Admins" /domain
net group "Schema Admins" /domain

# 특정 사용자 상세 정보
net user targetuser /domain
```

### PowerView
```powershell
Import-Module .\PowerView.ps1

# 도메인 사용자 열거
Get-DomainUser | Select-Object samaccountname, description, memberof

# 도메인 그룹 열거
Get-DomainGroup | Select-Object samaccountname, description

# 그룹 멤버십 확인
Get-DomainGroupMember -Identity "Domain Admins" -Recurse

# 도메인 관리자 계정 찾기
Get-DomainUser -AdminCount 1 | Select-Object samaccountname, admincount

# Kerberoastable 계정 (SPN 설정된 계정) 열거
Get-DomainUser -SPN | Select-Object samaccountname, serviceprincipalname

# AS-REP Roastable 계정 열거
Get-DomainUser -PreauthNotRequired | Select-Object samaccountname
```

### BloodHound
```powershell
# SharpHound 데이터 수집
Invoke-BloodHound -CollectionMethod All -OutputDirectory C:\temp\

# 또는 SharpHound 바이너리 사용
SharpHound.exe -c All --outputdirectory C:\temp\

# Stealth 수집 (탐지 회피)
Invoke-BloodHound -CollectionMethod DCOnly
```

### LDAP 직접 쿼리
```bash
# 도메인 사용자 LDAP 쿼리
ldapsearch -x -H ldap://192.168.1.10 -D "user@corp.local" -w "Password123!" \
  -b "DC=corp,DC=local" "(objectClass=user)" sAMAccountName memberOf

# 도메인 관리자 그룹 멤버 조회
ldapsearch -x -H ldap://192.168.1.10 -D "user@corp.local" -w "Password123!" \
  -b "DC=corp,DC=local" "(memberOf=CN=Domain Admins,CN=Users,DC=corp,DC=local)"
```

## 탐지 방법

### Sigma Rule
```yaml
title: Domain Account Discovery via Net Commands
id: a7e3f8c2-5b1d-4e9a-8c6f-3d2b7e5a1c4f
status: stable
description: Detects domain account and group enumeration via net.exe
logsource:
    product: windows
    category: process_creation
detection:
    selection:
        Image|endswith: '\net.exe'
        CommandLine|contains:
            - '/domain'
        CommandLine|contains:
            - 'group'
            - 'user'
    condition: selection
falsepositives:
    - IT administrators performing legitimate account inventory
level: medium
tags:
    - attack.discovery
    - attack.t1087.002
```

## 대응 방안

1. LDAP 쿼리 모니터링 및 비정상 대량 쿼리 탐지
2. BloodHound 수집 패턴 탐지 규칙 적용
3. 일반 사용자의 AD 열거 권한 최소화
4. AdminCount 속성 모니터링
5. Protected Users 그룹으로 특권 계정 보호
