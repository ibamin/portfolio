# T1552.001 — Credentials in Files

## 개요

**TA0006 / T1552.001**  
파일 시스템에 평문으로 저장된 자격증명을 탐색하고 수집하는 기법입니다. 설정 파일, 스크립트, 히스토리 파일, 무인 설치 파일 등에 패스워드가 하드코딩되거나 평문으로 저장되는 경우가 많습니다.

---

## 동작 방식

1. 패스워드가 포함될 가능성이 높은 파일 유형 및 경로 탐색
2. 키워드(password, pwd, secret, key 등)로 파일 내용 검색
3. 발견된 자격증명으로 내부 시스템 접근 또는 권한 상승

**주요 자격증명 저장 위치:**
- Windows: Unattend.xml, sysprep.inf, web.config, .env 파일
- Linux: ~/.bash_history, ~/.ssh/id_rsa, /etc/passwd, 환경변수
- Git 저장소: 커밋 히스토리 포함
- 클라우드: AWS credentials, .azure 디렉토리

---

## 주요 커맨드 / 실습

### Windows - 무인 설치 파일 검색
```cmd
# 무인 설치 파일에서 자격증명 검색
dir /s /b C:\sysprep.inf C:\sysprep\sysprep.xml C:\Unattend.xml
dir /s /b C:\Windows\Panther\Unattend.xml
dir /s /b C:\Windows\system32\sysprep\Unattend.xml

# 파일 내 패스워드 키워드 검색
findstr /si "password" *.xml *.ini *.txt *.config
findstr /si "pwd" *.xml *.ini *.txt
findstr /si "passwd" *.xml *.ini *.txt
```

### Windows - PowerShell 확장 검색
```powershell
# 자격증명 키워드 포함 파일 검색
Get-ChildItem -Path C:\ -Recurse -ErrorAction SilentlyContinue |
    Select-String -Pattern "password|passwd|pwd|secret|credential" |
    Select-Object Path, LineNumber, Line

# PSReadLine 히스토리 파일 확인
Get-Content $env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt

# .env 파일 검색
Get-ChildItem -Path C:\inetpub -Recurse -Filter "*.env" -ErrorAction SilentlyContinue
```

### Linux - 히스토리 및 환경변수 검색
```bash
# Bash 히스토리에서 자격증명 탐색
cat ~/.bash_history | grep -i "password\|passwd\|secret\|token\|key"

# 환경변수에서 자격증명 탐색
env | grep -i "password\|secret\|key\|token\|api"

# SSH 개인키 검색
find / -name "id_rsa" -o -name "id_dsa" -o -name "*.pem" 2>/dev/null

# 설정 파일에서 패스워드 검색
grep -r "password" /etc/ 2>/dev/null
grep -r "password" /var/www/ 2>/dev/null
```

### Gitleaks - Git 저장소 자격증명 검색
```bash
# 현재 저장소 전체 히스토리 스캔
gitleaks detect --source . --report-path gitleaks-report.json

# 특정 커밋 범위 스캔
gitleaks detect --source . --log-opts "HEAD~10..HEAD"

# GitHub 저장소 원격 스캔
gitleaks detect --source https://github.com/target/repo
```

## 탐지 방법

### Sigma Rule
```yaml
title: Credential Search via Findstr
id: b3a7f9e1-4c2d-4e8b-a5f3-1d6e9c4b7a2f
status: stable
description: Detects use of findstr to search for passwords in files
logsource:
    product: windows
    category: process_creation
detection:
    selection:
        Image|endswith: '\findstr.exe'
        CommandLine|contains:
            - 'password'
            - 'passwd'
            - 'pwd'
            - 'secret'
    condition: selection
falsepositives:
    - Legitimate administrative scripts
    - Software installations
level: medium
tags:
    - attack.credential_access
    - attack.t1552.001
```

## 대응 방안

1. CI/CD 파이프라인에 Gitleaks / TruffleHog 통합으로 커밋 전 자격증명 탐지
2. HashiCorp Vault, AWS Secrets Manager 등 비밀 관리 솔루션 도입
3. 환경변수 사용 감사 및 평문 저장 금지 정책 수립
4. git-secrets 훅으로 자격증명 커밋 방지
5. 설정 파일 접근 권한 최소화 (필요한 서비스 계정만 읽기 허용)
6. 정기적인 코드베이스 자격증명 스캔 실시
